```latex

```

# 14/07/2026: 

```latex
\documentclass[11pt]{article}

\usepackage[margin=1in]{geometry}

  

% Core packages

\usepackage{amsmath,amssymb}

\usepackage{tikz-cd}

\usepackage{multicol}

  

% Paragraphs

\setlength{\parindent}{0pt}

\setlength{\parskip}{1\baselineskip}

  

\title{Untitled}

\author{Author Name}

\date{\today}

  

\begin{document}

\maketitle

  

\section{Introduction}

  

\end{document}
```
